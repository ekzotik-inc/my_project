# Запуск «Добрых дел»

## Назначение и роли

Система использует два независимых уровня прав. **Chief Administrator** управляет структурой: командами, периодами, заданиями, рассылками, экспортом и Telegram-настройками. **P&C Administrator** принимает и отклоняет регистрации в боте, а также модерирует отчёты. Участник получает доступ к заданиям только после одобрения. Баллы добавляются только в момент подтверждения отчёта, а не в момент его отправки.

| Уровень | Где назначается | Доступ |
|---|---|---|
| Chief Administrator | Web-панель: роль владельца приложения `admin` | Полное управление системой и настройками Telegram |
| P&C Administrator | Карточка участника: роль `P&C Admin`; для доступа к web-модерации также роль пользователя `pc_admin` в разделе Database | Модерация регистраций и отчётов |
| Участник | Регистрация в боте и последующее одобрение | Задания, отчёты, личная статистика |

## Первичная настройка

Сначала Chief Administrator должен открыть Web-панель и создать команды. Только активные команды показываются участнику при регистрации. Затем создаётся один активный период, например «Добрые дела · Неделя 1». Для активного периода публикуются задания: каждое опубликованное задание получает каждый одобренный участник этого периода, что обеспечивает равное число заданий для всех.

| Шаг | Действие | Результат |
|---|---|---|
| 1 | Создайте команды в разделе **Команды** | Команды доступны при регистрации в боте |
| 2 | Создайте один активный период в разделе **Периоды** | Определены границы недели или другого срока |
| 3 | Создайте задания в разделе **Активности** | Все одобренные участники получают один и тот же набор заданий |
| 4 | Назначьте P&C Administrator в разделе **Участники** | Администратор может принимать заявки и проверять отчёты в Telegram |
| 5 | В разделе **Telegram** укажите каналы и публичный URL | Бот получает webhook и кнопку «Статистика» |

## Подключение Telegram

Добавьте бота в оба закрытых канала как администратора. Первый канал используется для заявок на регистрацию, второй — для отчётов по заданиям. Сохраните числовые chat ID обоих каналов в разделе **Telegram**. В поле публичного URL укажите корневой HTTPS-адрес опубликованного приложения, без `/statistics`: система самостоятельно настроит webhook по пути `/api/telegram/webhook` и кнопку Mini App на `/statistics`.

> Токен бота хранится только в защищённых переменных сервера. Не публикуйте его в чатах, коде или документах.

После сохранения Telegram-настроек бот автоматически получает URL webhook и кнопку меню. Участник запускает бота командой `/start`, передаёт контакт, ФИО и команду. Заявка сразу попадает в канал модерации, а участник видит только статус ожидания до принятия решения.

## Рабочий сценарий недели

При создании задания Chief Administrator задаёт описание, баллы, обложку и последовательность шагов. Тип шага ограничивает ожидаемый материал: фото, файл, текст или любой из этих форматов. По завершении всех обязательных шагов участник отправляет отчёт на проверку. Бот отправляет модератору материалы и кнопки решения; при отклонении модератор оставляет комментарий. При подтверждении создаётся запись в журнале баллов и обновляется командная статистика.

Рассылки создаются только в web-панели. Перед отправкой выберите аудиторию, добавьте текст, изображение и кнопки, проверьте отображение Telegram Markdown в предпросмотре, затем сохраните черновик. Отправка требует отдельного подтверждения и создаёт журнал успешных и неуспешных доставок.

## Статистика и экспорт

Кнопка **Статистика** открывает Telegram Web App. Приложение проверяет подписанные данные Telegram на сервере, а затем показывает только статистику текущего участника: личные баллы и прогресс, рейтинг топ-3, прогресс всех команд и последние действия. Доступ по обычной ссылке без Telegram не открывает персональные данные.

Раздел **Экспорт** создаёт свежий файл Excel с листами участников, заданий, отчётов, материалов отчётов, баллов и рассылок. Файлы доказательств остаются в защищённом файловом хранилище и представлены в Excel ссылками.

## Проверка перед стартом

Перед приглашением сотрудников проверьте, что у бота есть права администратора в обоих каналах, период активирован, есть как минимум одна активная команда и опубликовано нужное число заданий. Затем пройдите тестовую регистрацию с отдельного аккаунта, примите её в канале, отправьте тестовый отчёт с фото и текстом, подтвердите его и убедитесь, что баллы появились только после решения модератора.
