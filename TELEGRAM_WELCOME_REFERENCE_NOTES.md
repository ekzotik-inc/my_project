# Welcome-паттерн Telegram: применимость для «Добрых дел»

Источник: [официальный анонс Telegram, 25 августа 2026](https://telegram.org/blog/welcome-messages-buttons-TG-13/ru?ln=a).

Новая системная функция **«Приветствие»** Telegram настраивается владельцем группы или канала и показывается только новому участнику. Она поддерживает несколько сообщений, фото/видео и расширенное форматирование. Для личного диалога с ботом этот механизм не является заменой `/start`, поэтому переносится не буквально.

| Принцип референса | Собственная реализация в «Добрых делах» |
|---|---|
| Новый участник получает контекст без шума для остальных | `/start` показывает короткий личный welcome-маршрут только пользователю. |
| Несколько сообщений создают последовательный сценарий | Бот отправляет приветствие и отдельное навигационное сообщение с действиями, не смешивая регистрацию и справку. |
| Фото или видео формируют первый визуальный акцент | При наличии фирменной обложки используется image-first preview; без неё остаётся сильная typographic-композиция. |
| Кнопки делают текст интерактивным | Используются собственные inline-кнопки Bot API: «Начать регистрацию», «Как это работает», «Открыть мой маршрут». |
| Расширенное форматирование | Сохраняется проверяемый Markdown-safe слой для всех динамических данных. |

Не переносим чужие тексты, бренд, изображения или описание функций. Механика «Добрых дел» сохраняется: заявка проходит P&C-модерацию, задания равны для всех в периоде, а баллы появляются только после явного решения P&C.
