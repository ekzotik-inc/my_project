# Premium Emoji для «Добрых дел»

Этот документ фиксирует правила внедрения **только тех custom emoji, которые предоставлены пользователем в `TelegramiOSIcons.html`**. Они используются как смысловые маркеры, а не как декоративный шум.

## Технические правила

Telegram отображает custom emoji в HTML-разметке через `<tg-emoji emoji-id="…">обычный emoji</tg-emoji>`. Внутренний символ обязателен: он служит fallback для уведомлений, пересылок и клиентов, где анимированный custom emoji не отображается.[1] Бот может отправлять custom emoji в личные и групповые чаты, если владелец бота имеет Telegram Premium; также Telegram допускает их для ботов с дополнительными username на Fragment.[2]

Inline-кнопки поддерживают отдельное поле `icon_custom_emoji_id` и стили `primary`, `success` и `danger`.[3] Поскольку доступность custom emoji зависит от прав бота, транспорт должен повторить отправку с обычной иконкой/без стиля при отказе API — смысл сообщения не должен теряться.

## Правила композиции

В одном коротком сообщении используется **один акцентный custom emoji** у заголовка и, при необходимости, **один emoji в главной кнопке**. Системный статус не дублируется несколькими значками. Позитивные действия получают `success`, основной CTA — `primary`, а сценарии доработки сохраняют нейтральный тон без красной драматизации. Custom emoji не ставятся после каждой строки, рядом с персональными данными и в длинных абзацах.
