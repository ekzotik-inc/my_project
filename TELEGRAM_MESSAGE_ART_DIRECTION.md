# Редакционный язык Telegram-бота

## Принцип

Сообщение бота должно ощущаться как короткая личная записка от заботливой команды, а не как интерфейсная карточка. У каждого сообщения есть один главный акцент, достаточно воздуха и ровно одно понятное действие.

| Слой | Решение |
|---|---|
| Подпись | «Добрые дела» или контекст периода — тихий ориентир, не рекламный баннер. |
| Заголовок | Короткая мысль в жирном. Без россыпи emoji и без восклицательных серий. |
| Содержание | Человеческая фраза, факт, потом следующий шаг. |
| Признание | Баллы и подтверждение P&C показываются как результат вклада, а не игровая награда. |
| Кнопка | Глагол действия: «Начать задание», «Мой маршрут», «Принять результат». |
| Emoji | До одного символа-смысла на блок; Unicode остаётся гарантированным fallback. Собственные custom emoji подключаются только при предоставлении владельцем bot-owned ID. |

## Тон

Тон — спокойный, достойный и тёплый. Вместо «срочно», «ждёт», «начислено» используются формулировки «можно начать», «P&C уже смотрит», «ваш вклад подтверждён». Участника не подгоняют и не стыдят, а бережно возвращают к следующему реальному действию.

## Базовая форма

```text
*Добрые дела* · _контекст_
────────────

*Одна главная мысль*
Короткое объяснение без служебных деталей.

_Следующий шаг или принцип честной проверки._
```

Служебные статусы для P&C строятся по той же логике: сначала объект решения, затем необходимые факты, затем две контрастные кнопки решения.
