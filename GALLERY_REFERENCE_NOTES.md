# Gallery Reference Notes

Пользователь запросил общую галерею фото участников, ориентируясь на OriginKit **3D Stacked Carousel — WebGL Image Deck**: наложенные карточки, понятная глубина, поддержка нескольких изображений, управление направлением и параметрами ширины, высоты, промежутка и скорости.

Для Telegram Mini App не используется тяжёлый WebGL-рендер и автопрокрутка: это снизит риск просадок FPS на мобильных устройствах. Вместо этого галерея реализуется как ограниченный стек из CSS `transform`/`opacity`-слоёв с явными swipe и button действиями, `prefers-reduced-motion`, lazy decoding изображений и server-side pagination.

В публичную галерею могут попадать только изображения из отчётов с подтверждённым статусом. Карточка должна показывать минимально необходимый контекст: название активности, команду и дату; контактные данные, файлы чеков и текстовые ответы не раскрываются.
