# Participant Mini App — mobile design reboot

## Диагноз по реальному экрану

Текущий интерфейс смешивает тёмный hero, голубые обводки, белые card surfaces, сиреневые подложки, лайм, coral и тяжёлые тени. В результате каждый блок пытается стать главным, а content hierarchy теряется. Галерея дополнительно перегружена пятью крупными dark planes, поэтому фотография читается хуже, чем должна.

## Новая система

| Роль | Токен | Правило использования |
|---|---|---|
| Фон | `#F8F6F1` | Тёплая, спокойная основа всего Mini App. |
| Текст / ключевые hero | `#172033` | Один тёмный ink для читаемости и крупных смысловых блоков. |
| Primary | `#315FF4` | Только активная вкладка, CTA, focus и ключевая цифра. |
| Primary wash | `#EEF2FF` | Негромкая подложка для progress/metadata. |
| Confirmed | `#BDEB68` | Только утверждённый результат и полученное достижение. |
| Attention | `#FF8A70` | Только action, требующий внимания. |
| Borders | `#E8E5DF` | Тонкие нейтральные разделители, без голубых контуров вокруг каждой карточки. |

## Layout rules

- Контент располагается в одном vertical editorial flow с интервалом 16 px; крупный радиус остаётся только у hero и photo stage.
- Белая поверхность используется как один section sheet, а не как вложенная карточка внутри карточки. Внутри sheet — тонкие divider rows.
- Section label работает как тихая навигационная подпись; title и одно полезное число или действие являются единственным сильным акцентом секции.
- Фото — контент, а не декорация: одна передняя карточка с двумя слегка видимыми слоями глубины; caption лежит в нижней gradient safe-zone.
- Анимации — 180–260 ms на `transform` и `opacity`; никаких idle motion, inset glow и непрерывных перестроений layout.

## Объекты redesign

1. Achievement catalog: плоский section sheet, reward line без отдельной вложенной card, accordion rows с divider.
2. Activity feed: editorial list с маленьким initial mark, контекстной строкой и спокойно разделёнными событиями.
3. Gallery: три лёгких depth planes, нейтральная рамка, один photo stage, без каскада тяжёлых тёмных карточек.
4. Bottom navigation: единый фиксированный dock без лишней тени; cobalt pill — единственный выбранный control.
